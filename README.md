# Bring Component 🎉

## 📖 简介 | Introduction

### 🇨🇳 中文介绍

Bring Component 是一个 Figma 插件，帮你快速把选中实例的主组件召唤到旁边！不需要在组件库中找来找去，一键定位，效率翻倍 ✨

**功能特点：**
- 🎯 智能定位 - 自动找实例的父容器（Frame/Group/Component）
- 🧠 智能避障 - 自动找旁边的空位，避开其他元素
- 📦 组件集支持 - 同时处理单个组件和组件集
- 🌐 跨页面支持 - 即使组件在别的页面也能召唤

**使用方法：**
1. 在 Figma 中选中一个组件实例
2. 按 Cmd+K 搜索 "Bring Component" 并运行
3. 组件瞬间出现在你旁边！

---

### 🇺 English Introduction

Bring Component is a Figma plugin that instantly brings your selected instance's main component right next to you! No more digging through component libraries — one-click summon, double your efficiency ✨

**Features:**
- 🎯 Smart Positioning - Auto finds the instance's parent container (Frame/Group/Component)
- 🧠 Smart Collision Avoidance - Auto finds empty space next to it
- 📦 Component Set Support - Works with single components and component sets
- 🌐 Cross-Page Support - Works even if the component is on another page

**How to use:**
1. Select a component instance in Figma
2. Press Cmd+K, search for "Bring Component" and run it
3. The component appears right next to you instantly!
